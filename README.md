# I-Love-You-Inator

The ```I-Love-You-Inator``` is inspired by three sources:

- Phineas and Ferb's Dr.Doofenschmirtz for his whacky, whimsical, but methodical ["-inators"](https://github.com/lukeabela38/I-Love-You-Inator.git).
- This magnificent [video](https://www.youtube.com/watch?v=rXPpkzdS-q4) which explains my profession significantly better than I ever could.
- My wonderful girlfriend for whom I have built this as a recurring joke.

# Motivation

The ```I-Love-You-Inator``` seeks to answer a fundamental question which has long plagued humanity: "What if we apply software best practices to relationships?"

# Build Application

```
docker build -t i-love-you-inator .
```

# Run Application

```
docker run -it --rm i-love-you-inator
```
